# Zero Trust Dashboard — View Features

## One-Liner

**A unified command center for visualizing, monitoring, and managing Zero Trust network security across your entire organization.**

---

## Account View

- **Multi-Account Switching** — Instantly switch between Production, Staging, and Dev environments with one click
- **Account Health Status** — See real-time network health (Good/OK/Bad) for each account at a glance
- **Account Details** — View plan type, usage limits, team name, and billing information for the selected account
- **Editable Team Names** — Customize team display names per account with inline editing
- **Account Type Indicators** — Visual badges showing Enterprise, Business, or Pro plan levels

---

## Activity View

- **Real-Time Metrics** — Monitor live requests, throughput, errors, blocks, and latency with auto-updating sparkline charts
- **Traffic Flow Visualization** — Sankey chart shows data volume flowing through users, devices, and applications
- **Historical Playback** — Time-travel through past activity with adjustable speed (0.5x–8x) for incident investigation
- **Top Traffic Analysis** — View top edges by volume, top blocked connections, and top error-prone paths
- **Export & Reporting** — Generate compliance reports via PDF download or email with custom time ranges

---

## Objects View

- **Interactive Network Topology** — Visual map of all Zero Trust objects (users, devices, apps, policies, tunnels, gateways) and their connections
- **Summary & Expanded Modes** — Toggle between high-level object counts and detailed interactive graph
- **Filter & Focus** — Filter by object type and click any node to see details, relationships, and connected objects
- **Create & Connect** — Add new network objects and create connections via drag-and-drop handles
- **Traffic Indicators** — Edge thickness shows real-time traffic volume between connected objects

---

## Settings View

- **Authentication Configuration** — Set default identity provider, session duration, MFA requirements, and service tokens
- **Access Policy Defaults** — Configure default policy actions, geo-restrictions, device posture checks, and browser isolation
- **Logging & Alerts** — Enable activity logging, set retention periods, and configure real-time security alerts
- **Gateway & Tunnel Settings** — Configure WARP client requirements, split tunneling, and tunnel protocols
- **Advanced Controls** — API access, audit mode (dry run), and TLS minimum version settings
